# Music Player

A feature-rich music player that automatically extracts song metadata and displays album artwork while providing a modern listening experience.

## Features

- Audio Playback Controls
- Metadata Extraction
- Album Artwork Display
- Play/Pause Functionality
- Next & Previous Controls
- Progress Bar
- Responsive Design
- Dynamic Song Information
- Modern User Interface
- Local Audio File Support

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Supported Features

- MP3 Playback
- Metadata Reading
- Cover Art Display
- Track Navigation
- Real-Time Progress Tracking
